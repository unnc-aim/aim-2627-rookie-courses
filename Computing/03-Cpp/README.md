## 学习顺序

第一课从编译与解释、最小程序和流开始，包含 CMake 本地构建，再学习类型、条件、循环、容器、文本解析、函数、内存、引用、指针和结构体。

第二课承接第一课，依次学习类与封装、构造、对象接口、组合、生命周期、继承、多态、独占所有权和异常清理。

讲义包含介绍性正文以及全部 120 道题的完整题面、输入输出、约束、样例和初始代码。PPT 介绍概念，练习处只标题号。两课分别组织 S 与 O 题目。

## 使用材料

1. 按 [课前环境配置](ENV_SETUP.md) 准备本地编译环境。
2. 按对应讲义的学习顺序阅读介绍并完成练习。课堂入口由教师提供，CPP-Classroom 中每题保留一份完整 `.cpp`。
3. 第一课的 [CMake 演示](Lesson-1/CMakeIntro/README.md) 用已有 S01 说明本地配置、构建和运行。
4. 需要按题号查找材料时，查看 [独立题库](Exercises/README.md) 或 [120 题索引](Exercises.md)。
