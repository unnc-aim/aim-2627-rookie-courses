# S59 指针读写

第 1 课 · 1.10 · 指针——保存地址的变量，以及对象何时还有效

## 题目

x=5，用指针指向它并将其改成 9，输出 x 以及指针是否等于 &x。

## 样例输入

```text
（无输入）
```

## 样例输出

```text
9 true
```

## 逐步推导

指针先保存 &x，再通过 `*p` 写入；比较地址而不是硬编码十六进制值。

## 关键规则与边界

地址值受运行环境影响，不把实际地址写成固定期望输出。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int x = 5;
    int *p = &x;
    *p = 9;
    std::cout << x << ' ' << std::boolalpha << (p == &x) << '\n';
    return 0;
}
```
