# S08 故障分层

Lesson 1 · Chapter 01 · 从 Python 进入 C++ 程序

## 题目

程序读取一个整数并输出平方。输入保证绝对值不超过 1000。说明缺分号、未定义函数、结果错误各在哪一层发现。

## 样例输入

```text
7
```

## 样例输出

```text
49
```

## 逐步推导

运行程序验证平方，再分别制造一个编译、链接或逻辑故障；不要一次同时修改三处。

## 关键规则与边界

缺分号是编译错误，函数仅声明未定义常产生链接错误，平方写成 x+x 是逻辑错误。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int x = 0;
    std::cin >> x;
    std::cout << x * x << '\n';
    return 0;
}
```
