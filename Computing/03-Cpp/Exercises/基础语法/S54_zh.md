# S54 局部作用域

Lesson 2 · Chapter 01 · 函数：输入、计算与返回

## 题目

外层 x=1，内部代码块定义 x=2，先输出内层 x 再输出外层 x。

## 样例输入

```text
（无输入）
```

## 样例输出

```text
2
1
```

## 逐步推导

大括号内的同名 x 是新对象；离开块后重新看到外层 x。

## 关键规则与边界

内层声明遮蔽外层名字，离开作用域后内层变量生命周期结束。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int x = 1;
    {
        int x = 2;
        std::cout << x << '\n';
    }
    std::cout << x << '\n';
    return 0;
}
```
