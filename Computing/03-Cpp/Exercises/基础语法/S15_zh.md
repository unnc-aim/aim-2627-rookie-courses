# S15 浮点容差比较

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

输入两个 [-1000,1000] 浮点数，绝对差不超过 1e-6 输出 SAME，否则 DIFF。

## 样例输入

```text
0.3 0.3000001
```

## 样例输出

```text
SAME
```

## 逐步推导

差值可能为负，先取绝对值；恰等于容差仍归入 SAME。

## 关键规则与边界

本题明确绝对误差。工程中容差应结合量纲和数值规模决定。

## 完整单文件参考程序

```cpp
#include <cmath>
#include <iostream>

int main() {
    double a = 0.0, b = 0.0;
    std::cin >> a >> b;
    std::cout << (std::abs(a - b) <= 1e-6 ? "SAME" : "DIFF") << '\n';
    return 0;
}
```
