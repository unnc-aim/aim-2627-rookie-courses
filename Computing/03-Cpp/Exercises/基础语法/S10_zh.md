# S10 秒数拆分

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

输入 [0,1000000] 秒数，输出小时、分钟、秒，不补零。

## 样例输入

```text
3661
```

## 样例输出

```text
1 1 1
```

## 逐步推导

小时取整除 3600；分钟先按 60 换算再对 60 取余；秒数直接对 60 取余。

## 关键规则与边界

商表示完整单位，余数表示剩余部分。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int seconds = 0;
    std::cin >> seconds;
    std::cout << seconds / 3600 << ' ' << seconds / 60 % 60 << ' ' << seconds % 60
              << '\n';
    return 0;
}
```
