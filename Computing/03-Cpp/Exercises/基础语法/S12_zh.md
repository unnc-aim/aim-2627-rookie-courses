# S12 大整数乘法

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

输入两个 [0,10^9] 整数，输出乘积。

## 样例输入

```text
1000000000 1000000000
```

## 样例输出

```text
1000000000000000000
```

## 逐步推导

两个操作数直接声明为 long long，让乘法从一开始就在足够宽的类型中进行。

## 关键规则与边界

用足够宽的类型参与运算，不能等 int 溢出后才赋给 long long。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    long long a = 0, b = 0;
    std::cin >> a >> b;
    std::cout << a * b << '\n';
    return 0;
}
```
