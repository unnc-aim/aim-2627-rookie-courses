# S03 读取两个整数

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

读取两个 [-1000,1000] 整数，输出和与差。

## 样例输入

```text
8 4
```

## 样例输出

```text
12 4
```

## 逐步推导

两次提取依次给 a、b 赋值；先计算 a+b，再计算 a-b，不交换输入顺序。

## 关键规则与边界

提取运算符会跳过空白，空格和换行都可分隔整数。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int a = 0, b = 0;
    std::cin >> a >> b;
    std::cout << a + b << ' ' << a - b << '\n';
    return 0;
}
```
