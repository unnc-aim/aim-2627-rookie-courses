# S29 因子枚举

Lesson 1 · Chapter 05 · 条件与 for 循环

## 题目

输入 n∈[1,1000]，按升序每行输出一个正因子。

## 样例输入

```text
6
```

## 样例输出

```text
1
2
3
6
```

## 逐步推导

按 1 到 n 递增枚举，只有余数为 0 的候选才输出，因此结果自然升序。

## 关键规则与边界

范围小可以 O(n)。性能需求提高时再考虑平方根枚举。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int n = 0;
    std::cin >> n;
    for (int d = 1; d <= n; ++d) {
        if (n % d == 0)
            std::cout << d << '\n';
    }
    return 0;
}
```
