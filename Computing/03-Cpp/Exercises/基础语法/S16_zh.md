# S16 非负向上整除

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

输入 0≤n≤10^9、1≤k≤10^9，计算至少几个容量 k 的箱子能装下 n 件物品。

## 样例输入

```text
11 5
```

## 样例输出

```text
3
```

## 逐步推导

完整装满的箱数为 n/k，余数非零时再加一；n=0 时不增加箱子。

## 关键规则与边界

商加余数标记避免 n+k-1 的加法溢出，适用前提是非负 n、正 k。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    long long n = 0, k = 0;
    std::cin >> n >> k;
    std::cout << n / k + (n % k != 0) << '\n';
    return 0;
}
```
