# S73 有效数据统计

第 1 课 · 1.4 · 循环、输入结束与不断变化的状态

## 题目

输入 n 个读数，只有 [0,100] 有效，输出有效数和有效值总和。n≤1000。

## 样例输入

```text
4 -1 0 100 101
```

## 样例输出

```text
2 100
```

## 逐步推导

只有两个边界条件同时满足才更新计数与总和，二者在同一分支提交。

## 关键规则与边界

有效条件同时包含两个边界。全无效时计数和总和均为 0。

## 完整单文件参考程序

```cpp
#include <iostream>

int main() {
    int n = 0, valid = 0, sum = 0, x = 0;
    std::cin >> n;
    for (int i = 0; i < n; ++i) {
        std::cin >> x;
        if (0 <= x && x <= 100) {
            ++valid;
            sum += x;
        }
    }
    std::cout << valid << ' ' << sum << '\n';
    return 0;
}
```
