# S13 摄氏转华氏

第 1 课 · 1.2 · 为什么要写类型，算术结果为什么会变？

## 题目

输入摄氏温度 [-100,200]，按 F=C*9/5+32 输出一位小数。

## 样例输入

```text
25
```

## 样例输出

```text
77.0
```

## 逐步推导

先明确公式的乘除顺序，使用 9.0 和 5.0，再只在输出阶段保留一位小数。

## 关键规则与边界

9/5 会先得到整数 1，要让乘除表达式按浮点计算。

## 完整单文件参考程序

```cpp
#include <iomanip>
#include <iostream>

int main() {
    double c = 0.0;
    std::cin >> c;
    std::cout << std::fixed << std::setprecision(1) << c * 9.0 / 5.0 + 32.0 << '\n';
    return 0;
}
```
