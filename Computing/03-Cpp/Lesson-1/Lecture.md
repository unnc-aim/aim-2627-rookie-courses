## 1.1 程序、编译与输入输出流

你已经会写 Python 程序。进入 C++ 的第一步，是弄清源文件怎样成为正在运行的程序，以及数据怎样进出程序。

本节题号：S01、S02、S07、S08

### 源代码需要一种执行方式

源代码是人写的文本，处理器实际执行的是机器指令。常见 C++ 工具链先预处理源文件，再编译和汇编，得到目标文件，随后由链接器把所需定义和库连接成可执行程序。初学时可以先记住“构建成功，然后运行”这条主线。编译器负责检查语法和类型等规则，链接器还要为被调用的函数找到定义。一次点击运行可能同时触发多个构建步骤。

常见 Python 实现 CPython 也有编译步骤：源码通常先成为字节码，再交给解释器执行。我们平时直接运行 .py，往往看不到独立的构建命令。“编译型与解释型”适合用于比较常见使用方式，但不能简化成“Python 从不编译”或者“解释器只会逐行翻译”。这门课使用 C++17，平台接收一份完整的 .cpp 源文件，每次运行都重新开始程序。

| 常见工作流程 | 学生能观察到的过程 |
| --- | --- |
| CPython | 源代码编译为字节码，由解释器执行 |
| C++ 工具链 | 源代码经构建形成可执行程序，再启动运行 |
| 运行失败时 | 先确定错误发生在构建阶段还是程序运行之后 |

### 读懂一份完整程序

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!" << '\n';
    return 0;
}
```

以 # 开头的 include 是预处理指令，头文件让当前源文件看到需要的接口声明。main 是这里的程序入口，函数体由大括号围住，多数语句以分号结束。int 表示 main 返回整数退出状态。return 0 表示正常结束，它不会把数字 0 打印到输出区。输出内容和退出状态是两条不同的信息。

### 流连接程序和数据

把“流”先理解为程序连续读取或写入字符数据的接口。输入流把外部字符交给程序，输出流接收程序写出的字符。标准输入常连接终端或平台准备的输入，标准输出常连接终端或平台输出区，也可以重定向到文件，因此输入流不能直接等同于键盘，输出流也不能直接等同于屏幕。

| 名称 | 身份 | 初学时的用途 |
| --- | --- | --- |
| &lt;iostream&gt; | 头文件 | 提供标准流对象的声明及所需接口 |
| std::istream / std::ostream | 类型 | 分别表示输入流与输出流 |
| std::cin | 标准输入流对象 | 读取输入 |
| std::cout | 标准输出流对象 | 写出正常结果 |
| std::cerr | 标准错误流对象 | 写出诊断信息 |

std::cin 是 std::istream 类型的对象，std::cout 和 std::cerr 是 std::ostream 类型的对象。另一个类型名 std::iostream 表示同时支持输入与输出的流，要与 &lt;iostream&gt; 这个头文件名区分。std::cout &lt;&lt; value 把值的文本表示插入输出流，连续使用 &lt;&lt; 可以拼接多个字段。\n 是换行字符，std::endl 则在换行之外还会刷新输出缓冲。通常用 \n 表达普通换行。缓冲是暂存待处理字符的区域，不必要求每次写入立即出现在物理设备上。先学会接口的可观察行为，后面再看输入位置和失败状态。

### 用 CMake 描述一个本地项目

平台替你安排了单文件的编译和运行；本地项目则需要说明要构建什么、哪些源文件参与构建、采用什么语言标准。CMake 用 CMakeLists.txt 描述这些信息，并为本机生成合适的构建系统。构建工具再组织编译器和链接器完成工作。CMake、构建工具与编译器各有职责，安装 CMake 并不会自动代替 C++ 编译器。

| 工具 | 本次构建中的职责 |
| --- | --- |
| CMake | 读取项目描述、检查工具链并生成构建系统 |
| Make、Ninja 或 IDE 构建工具 | 按构建规则调用编译和链接步骤 |
| Clang、GCC 或 MSVC | 把 C++ 源代码编译、链接成程序 |

这里沿用已经完成的 S01，不新增题目。在本地创建一个文件夹，把 S01 的完整程序保存为 S01.cpp，再在同一目录新建 CMakeLists.txt，注意文件名的大小写和 .txt 后缀。源码目录保存你维护的文件，build 目录保存生成的构建文件与程序，两者分开，便于找到自己的代码。开始前在本地终端运行 cmake --version，确认命令可用，并准备好 C++ 编译器和相应构建工具。

```text
cpp-start/
    CMakeLists.txt
    S01.cpp
    build/
```

### 读懂最小 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(aim_cpp LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)
add_executable(S01 S01.cpp)
```

第一行要求使用至少 3.16 的 CMake，这个版本号与 C++17 的语言版本不是一回事。project 为项目命名，并用 CXX 表示项目需要 C++。三个 set 分别请求 C++17、要求编译器支持所请求的标准，并选择不使用编译器扩展的标准模式。它们放在目标创建之前，为后面创建的目标设置相应默认属性。

add_executable 声明一个可执行目标。第一个 S01 是目标名，后面的 S01.cpp 是参与构建的源文件名；项目名 aim_cpp、目标名 S01 与文件名 S01.cpp 分别承担不同职责。这里一个目标只选择一份带 main 的练习程序，不能把多道各有 main 的题随意拼进同一个目标。

### 配置、构建、运行是三个步骤

在包含 CMakeLists.txt 的目录中打开终端。先配置项目，-S . 指定当前目录为源码目录，-B build 指定生成文件放到 build 目录。配置成功说明项目描述和基本工具链检查通过，不等于你的程序已经编译成功。随后执行构建命令，才会真正编译和链接源文件。

```shell
cmake -S . -B build
cmake --build build
```

构建完成后，还需要启动生成的程序。在 macOS 或 Linux 常见的单配置构建中，可执行文件直接位于 build 中；Windows 单配置构建通常会加上 .exe 后缀。使用 Visual Studio 等多配置生成器时，可以执行 cmake --build build --config Debug，再到 build 的 Debug 子目录运行。下表列出当前最小项目的常见命令；实际路径取决于操作系统、生成器和构建配置。

| 常见环境 | 构建后的运行命令 |
| --- | --- |
| macOS / Linux 单配置 | ./build/S01 |
| Windows 单配置 | .\build\S01.exe |
| Windows 多配置 Debug | .\build\Debug\S01.exe |

修改 S01.cpp 并保存后，再执行 cmake --build build，然后重新运行程序。修改 CMakeLists.txt 后可以重新执行配置，再进行构建；一些生成器也会在构建时自动触发重新配置。若使用单配置生成器并希望启用 Debug，可在配置时额外传入 -DCMAKE_BUILD_TYPE=Debug；多配置生成器则在构建时用 --config Debug 选择配置。先掌握当前这一个目标的流程即可。

### 把构建错误放回相应阶段

找不到 CMakeLists.txt 时检查源码目录和文件名；找不到编译器时检查本机工具链；编译或链接失败时查看 C++ 诊断；构建成功却找不到程序时检查实际输出路径和配置。终端中的 cmake 命令属于本地工具操作，不写进 C++ 源文件。CPP-Classroom 的课堂练习继续提交单份 .cpp，CMakeLists.txt 用于本地项目，这两种运行方式都沿用相同的题号与源程序。

## 1.2 类型、变量与算术

Python 的变量知识可以直接帮助你理解赋值，但 C++ 还要求你明确对象的类型、初始化方式和数值范围。

本节题号：S03、S09、S10、S11、S12、S13、S14、S15、S16

### 声明、初始化和赋值

在 C++ 中，int count = 0 声明了一个 int 对象，并在创建时把它初始化为 0。后面再写 count = 5 是赋值，它修改一个已经存在的对象。Python 的名字可以重新绑定到不同类型的对象，而这里 count 的类型不会因为一次赋值而改变。这体现 C++ 的静态类型约束。Python 通常采用动态类型，对象具有类型，而名字可以绑定不同类型的对象。类型系统与编译、解释的执行方式是两个比较维度。未初始化的普通局部整数不能拿来直接计算；本课的写法都先给出明确初值。

```cpp
int count = 0;
double speed = 0.0;
bool ready = false;
const int limit = 100;
```

const 表示不能通过这个名字修改对象。它适合表达固定阈值等约束。单引号包围的 char 表达一个字符，例如方向指令；双引号表示字符串字面量。C++ 也有自动推导类型的写法，但这门入门课主要使用明确类型，让你能看出每个表达式正在进行什么计算。

### 选择足够的表示范围

| 类型 | 用途 | 需要留意的地方 |
| --- | --- | --- |
| int | 常见整数、计数与编号 | 有固定表示范围 |
| long long | 更大范围的有符号整数 | 适合大整数乘积和总和 |
| unsigned long long | 非负大整数 | 也有上界，不允许无限增长 |
| double | 测量值与实数计算 | 采用有限精度表示 |
| bool / char | 真假值 / 单个字符 | 不等同于任意整数或字符串 |

标准并不保证所有平台的 int 都恰好占四字节。课程平台常见 int 为 32 位，但程序选择类型时要看题目的范围。两个不超过 10^9 的整数相乘，结果可达到 10^18，需要更大整数类型。long long answer = a * b 只改变最终接收类型，如果 a 和 b 都是 int，中间乘法仍先按 int 计算。可以让操作数提前成为 long long，或在乘法前使用 static_cast&lt;long long&gt;。有符号整数溢出不能作为可靠的“自动绕回”。

### 输入是解析字符数据

std::cin &gt;&gt; a &gt;&gt; b 依次尝试按变量的类型读取两个值。格式化读取通常先跳过空格或换行，再解析数值，成功后继续从当前位置往后读。输入 12 和 34 时，分隔它们的是空白还是换行，通常不影响整数读取。这里先使用合法输入，下一节再学习读取失败时如何判断。

### 类型决定除法怎样计算

整数除法得到整数商，向零截断。3 / 2 的结果是 1，3.0 / 2 的结果是 1.5。Python 的 / 通常得到实数结果，// 按向下取整规则处理，负数情况下尤其不能把 Python // 和 C++ 整数除法当成同一种规则。% 表示整数余数，拆分秒数或十进制数位时可以结合商与余数使用。

```cpp
double ratio = static_cast<double>(a) / b;
long long product = static_cast<long long>(a) * b;
std::cout << std::fixed << std::setprecision(2) << ratio;
```

上面的 setprecision 需要 &lt;iomanip&gt;。和 fixed 配合时，它控制小数点后位数，格式设置会继续影响同一个流后面的输出。求平均值要让除法发生在浮点类型上；写到 double 变量里的整数商不会重新变回小数。计算摄氏温度换算时，同样要注意 9 / 5 和 9.0 / 5.0 的区别。

### 数学函数、近似值和向上整除

&lt;cmath&gt; 中的 std::sqrt 用来计算平方根，std::abs 可用于求差的绝对值。浮点值以有限精度表示，比较测量结果时常判断差值是否处在允许误差内，而不是机械地要求完全相等。题目若已经规定 1e-6 的容差，就严格按其绝对误差要求判断。

非负整数 n 放入容量 k 的箱子，k 必须为正。向上整除可以写为 n / k 加上“n % k 是否非零”的补偿项。常见的 (n + k - 1) / k 也需要确认加法不会超出类型范围。选择表达式时，范围分析应覆盖中间步骤。

## 1.3 条件判断与输入状态

条件、分支和逻辑仍然熟悉。需要重新确认的是运算符写法、短路求值，以及流怎样报告一次读取的结果。

### 条件由比较和逻辑组合而成

C++ 的 if 条件写在圆括号里，分支代码放进大括号。Python 的 elif 对应 else if。= 表示赋值，== 表示相等比较。区间判断必须写成 lower &lt;= x &amp;&amp; x &lt;= upper，不能照搬 Python 的连续比较写法。比较结果是 bool，可以用 &amp;&amp;、|| 和 ! 分别组合为并且、或者和取反。

```cpp
if (value >= lower && value <= upper) {
    std::cout << "SAFE" << '\n';
} else {
    std::cout << "UNSAFE" << '\n';
}
```

&amp;&amp; 只有在左边为真时才计算右边，|| 只有在左边为假时才计算右边。这种短路求值既能表达规则，也能保护操作。例如先确认分母不为零，再在右侧进行除法。判断“两个条件都成立”时用 &amp;&amp;；只有真的要对二进制位操作时才考虑 &amp;，不能因为外形相近就互换。

### 一次输入可能没有得到值

把整数读入 int 时，字符文本可能不符合格式，也可能超出 int 的范围。流会记录这次操作的状态。if (std::cin &gt;&gt; x) 会先读取，再根据流是否处于失败状态决定走哪个分支。它不能保证后面没有多余字符，例如读取 12abc 时整数提取可能先得到 12，把 abc 留在流里；整行是否合法要到字符串解析一节进一步验证。

| 观察方式 | 意思 |
| --- | --- |
| if (stream &gt;&gt; value) | 先尝试读取，再检查是否失败 |
| stream.fail() | 检查格式失败或底层严重错误状态 |
| stream.eof() | 检查是否已经遇到输入序列结尾 |
| std::boolalpha | 把布尔输出显示为 true / false |

遇到 EOF 与读取失败可以同时发生，但不是同一件事。比如最后一个合法整数恰好读到输入末尾，这次提取仍可成功，同时记录已经到达末尾。后续若再请求一个不存在的整数，读取才会失败。不要用 eof() 提前猜下一次读取是否能成功，应直接检查读取操作。

## 1.4 循环、EOF 与逐步变化的状态

循环把同一条规则应用很多次。写之前先回答：从什么状态开始，每次更新什么，什么时候停止。

本节题号：S25、S26、S27、S28、S29、S30、S31、S32、S73、S76、S79

### for 的执行次序

for (int i = 0; i &lt; n; ++i) 的初始化只执行一次，每轮先检查条件，执行循环体，再更新 i。i &lt; n 对应常见的半开区间 [0,n)，与 Python range(n) 的访问范围一致。++i 让 i 加一。若写成 i &lt;= n，就会多执行一轮；后续索引容器时，这一轮往往越过合法边界。

```cpp
long long total = 0;
for (int i = 0; i < n; ++i) {
    int value = 0;
    std::cin >> value;
    total += value;
}
```

这里每轮只读入一个整数并加入总和。累加器 total 的初值应该代表“还没处理任何元素”的结果。对于求和是 0，对计数也是 0；最大值则不宜随意初始化为 0，因为所有输入可能都为负数。先明确状态含义，再决定初值。

### 停止条件来自输入或者程序规则

while 每次先判断条件，再执行循环体。while (std::cin &gt;&gt; x) 会尝试读取，成功才进入循环，适合不知道输入个数、一直读到 EOF 的场景。哨兵值则是一条合法读入的数据，但它负责通知程序结束，不一定参与计算。需要在处理数据之前先检查哨兵。

### 状态必须按确定的顺序更新

最长连续长度通常需要两个状态：当前连续长度和历史最大长度。遇到不满足的元素时，只重置当前连续长度，历史最大值继续保留。过滤有效读数时，计数与总和都只在读数有效的分支更新。仿真中“先冷却，再判断，再执行”的顺序会影响结果，不能随意合并或交换。

| 时刻 | 需要问自己的问题 |
| --- | --- |
| 进入循环前 | 各状态代表什么，初值是否正确 |
| 处理当前项时 | 先检查还是先更新，是否应该跳过 |
| 本轮结束时 | 哪些状态保留到下一轮 |
| 循环结束后 | 没有任何输入时是否仍有合理结果 |

### 固定长度与动态长度

std::array&lt;int,5&gt; 表示装有五个 int 的固定长度容器，需要 &lt;array&gt;。std::vector&lt;int&gt; 表示可动态改变长度的整数序列，需要 &lt;vector&gt;。尖括号里的内容是类型参数或固定大小参数。现在先学会使用标准库提供的类型，不需要先实现模板。容器名后的点号用来访问它提供的成员操作，例如 values.size()。

```cpp
std::array<int, 5> fixed = {1, 2};
std::vector<int> values;
values.push_back(value);
```

这里 fixed 的其余元素会被零初始化。vector 初始为空，push_back 在末尾追加一项；vector&lt;int&gt; values(n) 则直接创建 n 个整数元素，初值为 0。size() 表示当前元素个数。固定长度和固定容量不是一回事，本课只按题目选择合适容器，不依赖内部如何分配内存。

### 索引要在合法区间内

### 复制整个容器会产生独立的值

Python 中 b = a 通常让两个名字指向同一个列表对象，修改其中一个列表元素会从另一个名字观察到。C++ 中 std::vector&lt;int&gt; b = a 创建一个 vector 副本，两者保存独立的整数元素，修改 b 的元素不会修改 a。这个对照只针对这里的整数容器，不能推广成“任何类型的复制都会递归复制所有外部资源”。引用、指针与对象成员会在后面分别讨论。

| 操作 | a 的状态 | b 的状态 |
| --- | --- | --- |
| 复制完成 | 原来的元素 | 与 a 内容相同的独立元素 |
| 修改 b 的一个元素 | 保持原值 | 对应元素改变 |

## 1.6 字符串、整行输入与字符扫描

字符串是一段字符序列。读入方式决定你得到一个词还是一整行，访问方式决定程序怎样逐步处理这些字符。

本节题号：S04、S05、S41、S42、S43、S45、S48、S69、S74、S77

### 字符和字符串是不同的类型

char 表示单个字符，常用单引号写字面量，例如 'U'。std::string 表示字符串对象，需要 &lt;string&gt;，常用双引号初始化。string 的 size() 返回长度，空字符串长度为 0。先判断字符串非空，才能访问首项与末项。题库中的这些文本处理题使用 ASCII 约束，按字节索引足以覆盖要求，不把同样的处理方式直接推广到中文字符。

与 Python str 不可变的习惯不同，C++ std::string 的字符可以通过合法下标修改。给字符串变量赋一个新值和修改现有字符串中的一个字符是不同操作。这里用现有题目学习最小接口，不介绍 C 风格字符数组和复杂编码转换。

### 格式化读取与整行读取

std::cin &gt;&gt; name 默认跳过前导空白，并读取到下一个空白之前，适合单词。std::getline(std::cin,name) 读取到换行分隔符，取走该分隔符但不把它保存进 name，适合带空格的一整行。若前面刚用 &gt;&gt; 读完一个数，留在流中的换行会使紧接着的 getline 得到空行。

| 操作 | 尚未读取的数据示意 |
| --- | --- |
| 输入内容 | 数字、换行、下一行名称、换行 |
| 提取数字之后 | 换行、下一行名称、换行 |
| 直接 getline | 读到第一个换行，得到空字符串 |
| 按规则跳过行尾后 getline | 得到下一行名称 |

std::ws 会消耗接下来的所有空白，包括换行和前导空格。只有在题意允许丢弃这些空白时，才使用 getline(std::cin &gt;&gt; std::ws,name)。若需要保留下一行的前导空格，可以先用 ignore 丢弃当前行剩余内容直至换行，再进行 getline；常见写法用 numeric_limits&lt;streamsize&gt;::max() 指定足够大的丢弃上限，需要 &lt;limits&gt;。S05 已限制名称没有前导空格，但读懂这两种做法的差异仍然重要。

## 1.7 字符串流与严格解析

输入流可以连接标准输入，也可以连接内存中的字符串。两者都能使用格式化提取，这让“读一整行，再验证字段”成为自然的处理方式。

本节题号：S44、S46、S47、S75

### 同样的流接口，更换数据来源

&lt;sstream&gt; 提供基于字符串的流。std::istringstream 从一段字符串提取值，std::ostringstream 把值格式化写入字符串，std::stringstream 同时支持读与写。可以把它们看成由字符串缓冲承接数据的流接口。Python 的 io.StringIO 也有把字符串当作流使用的用途，如果你没用过它，直接从本节的读写过程理解即可。

| 类型 | 主要方向 | 常见用途 |
| --- | --- | --- |
| istringstream | 字符串内的数据进入变量 | 分词、字段解析、读取数值 |
| ostringstream | 变量的文本表示进入字符串 | 组合、格式化一段文本 |
| stringstream | 同一字符串缓冲支持输入和输出 | 需要两种方向的文本流操作 |

字符串、字符串流对象、流内的缓冲内容是需要区分的概念。初始化流时给出的文本成为其缓冲内容，随后 &gt;&gt; 推进读取位置；读取变量不会自动修改原来的 string 变量。写入输出字符串流后，可以调用 str() 取得当前文本。str() 不表示“读取一个单词”，它访问的是整个缓冲内容。

```cpp
std::istringstream input(line);
int value = 0;
input >> value;

std::ostringstream output;
output << value;
std::string text = output.str();
```

### 空白分词与指定分隔符

## 1.8 函数、作用域与值传递

函数把计算的输入、输出和局部状态放在一个清楚的边界内。先理解值怎样传进去，再讨论怎样允许函数修改外部对象。

### 函数接口说明什么

C++ 函数在名字之前写返回类型，在参数列表里逐个写参数类型。调用表达式把实参值交给形参，return 把结果交回调用方。没有返回值的函数可以使用 void。与 Python def 相比，显式类型让编译器在调用处检查参数是否符合接口。函数应该完成一件能清楚描述的事，例如限幅或计算一个结果。

```cpp
int add(int a, int b) {
    return a + b;
}
```

调用函数时，编译器需要已经看见合适的声明。可以把整个定义放在 main 之前，也可以先写函数声明，在后面给定义。声明说明接口，定义提供函数体。它们的参数类型和返回类型必须对应。平台练习继续把这些内容保留在一个 .cpp 文件里，不需要先引入多文件构建。

## 1.9 内存、地址与引用

在写出 &amp; 之前，先建立一个模型：对象占用存储，存储中的内容有类型解释，地址用于标识所在位置。

本节题号：S58、S56、S62

### 位置与内容需要分开理解

内存可以简化想象为一串有编号的存储单元，字节是观察对象大小时常用的单位。C++ 中一个字节至少能容纳八位，现代常见平台一般为八位。一个 int 往往占用连续的多个字节，sizeof(int) 可以取得当前实现中的大小。地址描述对象所在的位置，值描述对象存储的内容；地址数值与对象里保存的整数不是同一个东西。

下面的地址只用来辅助理解，不是任何题目的固定输出。不同运行、不同机器甚至编译选项都可能改变实际地址。初学时不需要从地址推导真实硬件布局，也不需要假定所有局部变量一定按代码顺序紧邻存放。

| 对象或名字 | 示意位置 | 当前内容 |
| --- | --- | --- |
| x | 0x1000 | 整数 5 |
| y | 0x2000 | 整数 5 |
| 引用 ref | 与 x 关联 | 通过它访问 x |

### 复制值和增加别名

int y = x 会创建另一个整数对象，它从 x 当前的值开始，但之后拥有独立状态。int&amp; ref = x 则让 ref 作为访问 x 的另一个名字。通过 ref 赋值就会修改 x。普通左值引用初始化时需要绑定合适对象，后面的赋值不会让它改绑到另一个对象，而是修改已经绑定的目标。

```cpp
int x = initial;
int copy = x;
int& ref = x;
ref = updated;
```

表达式 &amp;x 取得 x 的地址，而声明 int&amp; ref 中的 &amp; 是引用类型的一部分。把两者写在不同位置看，比把 &amp; 背成一个固定中文词更准确。&amp;ref 与 &amp;x 比较会反映它们关联同一个对象；这不表示标准要求引用必须以某种特定的指针布局实现。

### 引用参数让函数访问原对象

函数参数改成 int&amp; a 后，调用时 a 绑定调用方提供的整数对象，修改 a 就会影响原对象。交换两个引用参数时，要先保存其中一个旧值，再完成两次赋值，不能在旧值丢失后恢复它。这里的意义是参数机制，与交换算法本身分开理解。

```cpp
for (const int& item : values) {
    // read item
}
```

## 1.10 指针、区间与对象有效期

引用提供别名，指针则把地址作为一个可以保存和修改的值。只有同时理解“指向哪里”和“目标还活着吗”，才能安全使用它。

本节题号：S59、S60、S61、S64、S63

### 指针变量与目标对象

int* p 声明一个指向 int 的指针对象。int* p = &amp;x 把 x 的地址保存到 p。p 本身也占用存储，保存的内容是地址值；x 是另一个对象，保存整数值。表达式 *p 通过 p 保存的地址访问目标对象，这个操作叫解引用。声明中的星号、解引用表达式中的星号和乘法运算符需要按位置区分。

```cpp
int* p = &x;
*p = updated;
p = &other;
```

| 语句 | 改变谁 | 保持什么 |
| --- | --- | --- |
| *p = updated | 当前指向的目标对象 | p 保存的地址 |
| p = &amp;other | 指针对象 p | 原目标对象的内容 |

一个普通指针可以重新保存另一个地址，引用则保持原来的绑定关系。指针复制只复制地址值，两份指针可以访问同一个目标，并不会复制目标对象。这也说明“值复制”不等于所有可达资源都深复制。

### 地址本身不携带区间长度

把内建数组传给接受指针的参数时，常会转换为首元素指针。指针并不会自动告诉函数后面还有多少个元素，因此指针区间接口通常同时接收 p 和 n。只有 i 在 [0,n) 且这些元素确实存在时，p[i] 才有意义。本课的 sum_span 是普通自定义函数名，不是 C++20 的 std::span。

约定 n = 0 时允许 p = nullptr，意味着函数在空区间内不得解引用 p，也不能为了“试试看”先访问 p[0]。非空时，调用方负责提供足够长且存活的连续区间。标准容器通常更容易携带长度信息，因此实际接口应优先考虑能明确表达范围的形式。

### 函数返回后，哪些对象仍然存在

普通局部对象在相应作用域结束时销毁。返回它的地址或引用，并不会延长它的生命；调用方拿到的访问入口会悬空，继续使用它属于未定义行为，不能靠“某次运行还能读出旧值”证明安全。返回新创建的数据时，按值返回通常是自然选择。

return values 可以把一个 vector 结果交给调用方。实现可能通过复制消除或移动等方式避免不必要的完整复制，初学时先掌握语义：调用方得到一个有效的结果对象，不再借用函数里已经结束的局部对象。第二课会进一步讨论对象的构造、析构与独占所有权。

## 1.11 结构体、枚举与记录集合

本节题号：S65、S67、S66、S71、S72、S80

### 结构体把相关字段放在一起

一条遥测记录可能同时包含编号、血量和速度。把它们分别保存在互不关联的数组里容易错位，struct 可以把字段组织成一个类型。定义末尾需要分号，成员用点号访问。与 Python 字典相比，结构体在类型定义中明确写出字段名和字段类型，编译器据此检查访问。

```cpp
struct Frame {
    int id = 0;
    int hp = 0;
    double speed = 0.0;
};
```

Frame value 创建该类型的一个对象。vector&lt;Frame&gt; 则保存一批同类型记录。通过 Frame&amp; 遍历时可以把输入直接写入每条记录，通过 const Frame&amp; 遍历时表达只读访问。这正好使用前两节建立的引用概念。结构体还可以有成员函数，下一课再从这里发展到类和封装。

### 比较规则要完整处理平局

最近目标可以比较到原点距离的平方，避免在只比较大小时额外开平方。若距离相同，还要按编号比较，这个平局规则必须写成第二层判断。排序也是同样的思想：比较器返回“第一个对象应排在第二个前面”是否成立。相等对象不能互相都被判定在对方前面。

std::sort 来自 &lt;algorithm&gt;，begin() 与 end() 表达待排序的半开范围。可以把已学的普通函数作为比较器；也可以读懂现有参考实现里的简短 lambda。[] 是捕获列表，参数仍然按普通函数的方式声明，函数体返回 bool。本组比较器只需要读取参数，可用 const 引用，不必引出完整的 lambda 或迭代器专题。

```cpp
bool before(const Record& a, const Record& b) {
    if (a.score != b.score) {
        return a.score > b.score;
    }
    return a.id < b.id;
}
```

### 筛选、去重与报表
