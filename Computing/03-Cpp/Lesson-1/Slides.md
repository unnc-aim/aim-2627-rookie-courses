- vector 可以保存多个记录对象

## 71. 作用域枚举

- enum class 为有限状态命名
- 使用 类型名::枚举值 访问
- 与整数交换数据时显式转换
- 输入编号仍需要满足范围约束

## 72. 排序比较器

```cpp
bool before(const Record& a,
            const Record& b);
```

- 返回 a 是否应排在 b 前面
- 先比较主关键字
- 相同时应用平局规则
- 相等时不能互相排在对方前面
